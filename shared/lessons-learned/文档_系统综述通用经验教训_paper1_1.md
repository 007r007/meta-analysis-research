## 一、最重要的原则：写法决定提取

**最大教训：先确定写作框架，再设计数据提取表。**

我们在 Paper-01 中走了弯路：先建了 v1 表格，发现字段不够，改了 v2，又发现漏了字段，再改 v3。前后三版，根本原因是没有先想清楚"文章每一节需要什么数据"。

**正确顺序：**
```
1. 确定研究问题和框架
2. 写出文章大纲（到小节级别）
3. 逐节问："这节需要哪些数据？"
4. 汇总得到提取字段清单
5. 设计提取表
6. 开始提取数据
```

## 二、数据提取表设计原则

### 2.1 字段分类框架（适用所有综述）

**A. 文献基本信息（必须）**
- 序号、第一作者、年份、标题、期刊、国家
- 发表状态（期刊正刊/预印本）

**B. 样本特征（必须）**
- 总样本量N
- 训练组N、对照组N（有对照组的研究）
- 年龄均值 + 年龄SD
- 性别（%女）
- 教育年限（年）
- 临床/认知筛查工具 + 分数
- 样本来源（社区/大学/医院）
- **失访率/完成率（%）**——老年研究必须，影响RoB

**C. 研究设计（必须，且必须是第一个填的字段）**
- **研究设计类型**（RCT/准RCT/单组前后测/交叉设计）
- ⚠️ 这个字段决定：RoB用哪个工具、"总体结论"怎么判断、Results怎么分层

**D. 干预特征**
- 训练类型（n-back/span/其他）
- 训练任务名称（具体软件/任务）
- 是否自适应
- 训练总次数（sessions）
- 每次时长（分钟）
- 训练周数
- 训练频率（次/周）——可由sessions÷周数计算
- 监督方式（实验室/居家/混合）
- 训练平台/软件
- 是否联合其他干预（tDCS/TMS/运动等）
- **失访率/完成率**（同B类重复，但在干预语境下更有意义）

**E. 对照组（有对照组时必须）**
- 是否主动对照（是/否）
- 对照组任务类型（具体描述）

**F. 结局测量**
- 近迁移（是/否）+ 近迁移结局变量名称
- 远迁移（是/否）+ 远迁移结局变量名称
- **远迁移结局域分类**（流体智力/EF/情景记忆/日常功能/其他）
- 维持随访（是/否）+ 随访时间点（月）
- 效应量是否报告（是/否）+ Cohen's d值
- **统计方法**（ANOVA/ANCOVA/LMM/其他）

**G. 结论判断（必须，且是高风险字段）**
- **总体结论**（正向/无效/混合）
  - 定义：同一研究内结局指标方向不一致=混合（参考Sala & Gobet, 2017）
  - 有对照组→看组间差异；无对照组→看前后测
  - ⚠️ 这是错误率最高的字段，必须人工核查

**H. 调节因素（根据综述主题定制）**
- 基线认知水平（高/低/未报告）
- 显式调节效应检验（是/否）+ 方向
- 年龄亚组分析（是/否）
- 认知储备指标 + 是否显著调节
- **任务认知过程重叠度**（高/中/低/未报告）——Paper-01的创新点

**I. 神经影像（如有）**
- 神经影像结局（是/否）
- 影像类型（fMRI/EEG/ERP等）
- 主要发现

**J. 偏倚风险（必须，PRISMA 2020强制）**
- RoB总体等级（低/有顾虑/高）
- 详细维度（单独Sheet）：D1-D5各维度评级

---

### 2.2 字段数量建议

| 综述类型 | 建议字段数 | 说明 |
|---------|----------|------|
| 叙述性系统综述 | 40-60列 | 不要过度设计 |
| Meta分析 | 60-80列 | 需要原始统计数据用于效应量计算 |
| 快速综述（二区） | 25-35列 | 聚焦核心字段 |

## 三、哪些字段必须人工判断，哪些可以自动化

### 3.1 必须人工判断（AI判断不可靠）

| 字段 | 原因 | 风险等级 |
|------|------|---------|
| **总体结论（正向/无/混合）** | 需综合判断多个结局指标，AI容易看Abstract而非Results | 🔴 极高 |
| **任务认知过程重叠度** | 需要认知神经科学专业知识，是综述的学术贡献所在 | 🔴 极高 |
| **偏倚风险（RoB）各维度** | 需要方法学判断，不同研究描述方式差异大 | 🔴 极高 |
| **近迁移/远迁移（是/否）** | 边界案例判断需要领域知识（什么算"相似任务"） | 🟡 高 |
| **是否主动对照** | "低强度认知任务"算主动还是被动，有争议 | 🟡 高 |
| **纳入/排除标准边界案例** | "健康老年人"如何界定，SCD算不算 | 🟡 高 |

### 3.2 AI可以高质量完成（CC/Kimi处理）

| 字段 | 自动化方式 | 可信度 |
|------|----------|-------|
| **训练频率** | sessions÷周数，脚本计算 | ✅ 99% |
| **年龄段分类** | 年龄均值≤75=young-old，脚本计算 | ✅ 99% |
| **数值字段提取**（样本量、年龄、sessions等） | PDF提取，原文通常有明确数字 | ✅ 90%+ |
| **分类字段提取**（国家、期刊、训练类型） | PDF提取，通常无歧义 | ✅ 85%+ |
| **结局变量名称** | PDF提取，照抄原文 | ✅ 85%（措辞不统一需后处理） |
| **偏倚风险预评估** | Kimi批量读PDF预标注，人工核查 | ⚠️ 70%（需人工确认） |

### 3.3 建议工作流

```
CC/Kimi 批量提取数值+分类字段
    ↓
CC 脚本计算衍生字段（频率、年龄段等）
    ↓
CC 生成异常值报告（标出可疑数据）
    ↓
你（人工）核查：总体结论、近/远迁移判断、对照类型
    ↓
你（人工）填入：任务认知过程重叠度（核心创新，必须你判断）
    ↓
Kimi 批量预评 RoB（D1-D5）
    ↓
你（人工）核查边界案例并最终确认RoB
```

## 四、数据提取表版本管理

**经验教训：** Paper-01 经历了 v1→v2→v3 三个版本，大量时间浪费在重新设计表格上。

**正确做法（下次从一开始就做）：**

1. **v1 = 草稿**：按写作框架设计，包含所有字段
2. **在正式提取前**：拿3-5篇文献试提取，发现字段缺漏
3. **vFinal = 最终版**：试提取后修订，确认后不再改动
4. **提取过程中**：只填数据，不改结构

## 六、研究设计异质性处理原则

**场景：** 56篇文献包含RCT、准实验、单组前后测、交叉设计。

**错误做法：** 把所有设计混在一起不加区分地报告结论。

**正确做法：** 分层报告，不排除，但区分证据质量。

**写法模板（Results每小节）：**
```
"共X篇研究考察了[调节因素]。
其中Y篇RCT、Z篇准实验、W篇单组设计。

RCT证据（n=Y）：[描述发现，给出一致性]
非RCT证据（n=Z+W）：[描述发现]

综合来看，[结论]。证据一致性评级为：
consistent（>75%一致）/ moderate（50-75%）/ mixed（<50%）/ insufficient（<3篇）"
```

**"总体结论"的判断标准（引用Sala & Gobet, 2017）：**
- 正向：该研究主要结局指标全部或大多数显著（训练组优于对照组）
- 无效：所有主要结局指标均无显著差异
- 混合：部分显著，部分不显著（同篇文章内）

## 七、效应量处理原则

**叙述性综述：**
- 有报告→记录下来，描述性引用
- 没报告→记为"未报告"，在Limitations里指出
- **不需要**强制要求每篇都有效应量

**如果将来想升级为Meta分析（需要从原文反推效应量）：**
- 需要额外提取：均值(M) + 标准差(SD) + N（各组）
- 或：t值/F值 + N（各组）
- 工具：`esc` R包（Effect Size Computation）
