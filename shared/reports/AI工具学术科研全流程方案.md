## 二、各阶段详细方案

### 阶段 1：选题探索与研究问题凝练

| 工具 | 用途 | 具体操作 |
|------|------|---------|
| **Elicit**（免费） | 快速扫描领域文献量 | 输入研究问题 → 查看"约X篇相关文献" → 判断选题可行性 |
| **Claude Opus 4.6** | 综述缺口分析 | 上传核心竞争文献PDF → 要求"列出该文未解决的问题和值得扩展的方向" |
| **Consensus**（免费） | 证据方向确证 | 输入Yes/No型研究问题 → 看Consensus Meter → 判断结论是否有争议空间 |

**本阶段工作流：**
```
1. Elicit 输入 3–5 个候选研究问题 → 查看文献量
2. Consensus 验证核心假设是否有争议
3. Claude Opus 4.6 阅读 2–3 篇核心竞争文献 → 生成差异化定位
4. 确认选题可行性 → 进入阶段 2
```

**注意事项：**
- Elicit 和 Consensus 主要覆盖英文文献，中文文献需上知网单独检索
- 两个工具检索同一问题的文献重叠度极低（见 Huang & Williamson, 2025），建议 Elicit + Semantic Scholar 双检

---

### 阶段 2：系统文献检索

| 工具 | 角色 | 具体操作 |
|------|------|---------|
| **Semantic Scholar** | 主检索引擎 | 布尔逻辑检索 → 按引用量/年份排序 → 导出BibTeX |
| **ResearchRabbit** | 引文网络追踪 | 以 3–7 篇种子文献为起点 → 自动前向/后向引文追踪 → 可视化关系图 |
| **Connected Papers** | 文献谱系重建 | 输入经典文献 → 生成学术家谱 → 找到"漏网"文献 |

**本阶段工作流：**
```
1. Semantic Scholar 执行系统检索（布尔组合）→ 导出结果
2. 选出 3–7 篇核心文献作为"种子"
3. ResearchRabbit 基于种子做引文网络扩展 → 找到被传统检索遗漏的文献
4. Connected Papers 对经典文献做谱系图 → 确认是否有关键前驱研究被忽略
5. 传统数据库（PubMed + PsycINFO + WoS + Scopus）补检 → 导出到 Zotero
```

**关键原则：**
- **多工具互不可替代** — 2025年实测发现，SciSpace、Semantic Scholar、Elicit、ResearchRabbit 返回结果的重叠度极低
- 最终仍须走传统数据库流程（PubMed/PsycINFO/WoS/Scopus）以符合 PRISMA 要求

---

### 阶段 3：文献筛选与数据提取（系统综述/元分析核心）

| 工具 | 角色 | 具体操作 |
|------|------|---------|
| **Elicit 系统评价工作流** | 主力 | 设置纳入/排除标准 → AI自动分类 → 人工复核 → 提取PICO数据到结构化表格 |
| **Claude Opus 4.6** | 数据验证 | 上传PDF全文 → 要求"从本文提取以下变量：样本量、ERP成分、行为任务、效应量..." |

**Elicit 系统评价工作流详解：**
```
1. 创建项目 → 设置研究问题
2. 导入检索结果（支持RIS/BIB/PubMed ID）
3. 定义纳入/排除标准（如：被试年龄≥6岁、ERP实验、双语比较设计）
4. AI自动筛选 → 输出透明筛选表（每个标准是否满足均有记录）
5. 人工复核AI判断 → 修正错误分类
6. 定义提取字段 → AI批量提取（样本量、ERP成分、效应量等）
7. 导出结构化表格 → 进入阶段5（写作）
```

**⚠️ 关键警告：**
- Elicit 的敏感性实测仅 **40%**（UHMLG 2025年评估：人类找到15篇，Elicit仅找到6篇）
- **切勿**用Elicit替代完整数据库检索，它仅适合辅助筛选阶段

---

### 阶段 4：文献深度阅读与理解

| 工具 | 角色 | 具体操作 |
|------|------|---------|
| **SciSpace Copilot** | 快速阅读 | 打开PDF → 划词获取解释 → 对全文提问 |
| **Claude Opus 4.6** | 深度分析 | 上传PDF → 要求"总结研究方法、ERP成分、主要发现、局限性" |

**SciSpace 使用技巧：**
- 对每篇文献问同一套问题：① 研究设计类型？② 被试特征？③ 关键ERP成分及潜伏期？④ 行为指标？⑤ 效应量？
- 这会生成一致格式的阅读笔记

**Claude 使用技巧：**
- 200K token 上下文 = 可同时上传 3–5 篇全文，要求横向对比方法学差异
- 对ERP研究：要求"提取N1/P2/N2/P3/LPC成分的峰值、潜伏期和统计结果"

### 阶段 5：论文撰写与润色

#### 5.1 大纲与结构

| 工具 | 推荐理由 |
|------|---------|
| **DeepSeek R1** | 逻辑结构组织最强（医学综述实测"最佳大纲助手"） |
| **Claude Opus 4.6** | 大纲细节丰富，学术风格更正式 |

#### 5.2 英文正文撰写

| 工具 | 角色 | 优势 |
|------|------|------|
| **Claude Opus 4.6** | 主力写作 | 写作自然度最优、不公式化、适合长文 |
| **GPT-4o / o3** | 段落润色 | 速度最快、成本最低、多样性好 |

**写作分级策略：**
```
初稿 → Claude Opus 4.6（200K上下文同时处理全文，保持一致性）
段落润色 → GPT-4o（逐段提交，要求"提高学术严谨性，保持原意"）
引用整理 → Claude（GB/T 7714 或 APA 7th格式化）
最终审阅 → Claude Opus 4.6（一次性阅读全文，检查逻辑连贯性）
```

#### 5.3 中文论文撰写

| 工具 | 推荐理由 |
|------|---------|
| **DeepSeek R1** | 中文学术写作最强、专业术语准确、知网文献理解好 |
| **Qwen 2.5 Max** | 中文备选，国内学术生态整合 |
| **Claude Opus 4.6** | 中文也不差，但专业术语偶有偏差 |

#### 5.4 参考文献格式

| 工具 | 用途 |
|------|------|
| **Claude Opus 4.6** | 文献条目 → APA 7th / GB/T 7714 格式化 |
| **Zotero** | 文献库管理，配合 Better BibTeX 插件 |

## 五、学科特异性建议（认知神经科学/ERP研究）

### ERP 文献搜索最佳关键词策略

```
主题关键词：ERP, event-related potential, N400, P600, N170, MMN,
           LPC, LAN, N2/P3 component
人群关键词：bilingual*, reading, dyslexia, Chinese-English, L1/L2
方法关键词：priming, lexical decision, semantic judgment, auditory/visual
```

### Elicit 筛选模板（供 Paper-02 使用）

```
纳入标准：
1. 被试：双语者（汉英），年龄 6–15 岁
2. 方法：ERP实验，至少报告 1 个经典成分（N1/N2/P2/N400/P600/LPC等）
3. 设计：至少 1 个阅读相关任务
4. 比较：至少报告组间比较（阅读障碍 vs. 典型发展 / L1 vs. L2）
5. 语言：英文或中文全文
6. 时间：2000–2026

排除标准：
1. 纯行为实验（无EEG/ERP）
2. 综述/元分析/评论文章
3. 被试为成人失语症/获得性阅读障碍
4. 仅报告fMRI/MEG/fNIRS数据
```

## 七、核心警告汇总

1. **引用虚构** — 所有 LLM 的引用真实性 50–64%，必须人工逐条核实
2. **工具重叠度极低** — Elicit、Semantic Scholar、SciSpace、ResearchRabbit 返回不同结果，至少组合 2–3 个
3. **Elicit 不是替代品** — 敏感性仅 40%，系统检索仍须走 PubMed/PsycINFO/WoS/Scopus
4. **中文文献覆盖差** — 所有工具对知网/万方文献支持弱，中文检索须走知网
5. **AI 只是辅助** — 过度依赖导致"认知钝化"和"理解错觉"
6. **多模型策略优于单模型** — 没有模型在所有维度均最优
