## 二、比较层重编码方案（核心）

数据单位：**独立试验 → 臂 → 比较 → 结局 → 时间点**

每篇提取字段：

| 字段 | 说明 |
|---|---|
| trial_id | 去重后编号（主报告 Seq + 次要报告 Seq） |
| arms | 全部臂（干预组/对照组/各臂收到什么） |
| comparison | 实际组间比较（谁比谁） |
| comp_type | 四类：①W vs C ②W+X vs C+X ③W+X vs W+sham-X ④W+X vs C |
| est_target | 该比较估计的是什么（WM效应 / WM增量 / X增益 / 组合效果） |
| co_intervention_正确 | 从 Methods 重判（非关键词），受控词表：无/tDCS/TMS/tRNS/运动/药物/多标签 |
| 元数据修正 | 作者/N/国家/年龄/年份，逐项对 PDF 修正 |
| 效应量可提取性 | 是否报告 mean/SD/change/t 统计量（决定能否进元分析） |

**四类比较定义（判定标准）**：
- ① **W vs C**：WM 训练 vs 非 WM 对照 → 估计"WM 训练效应"（可进核心元分析）
- ② **W+X vs C+X**：WM+附加 vs 对照+同一附加 → 估计"在 X 背景下 WM 的增量"（可进核心元分析，标注共同 X）
- ③ **W+X vs W+sham-X**：WM+刺激 vs WM+假刺激 → 估计"刺激增益"，**不能当 WM 效应**（单独综合或排除）
- ④ **W+X vs C**：WM+附加 vs 无附加对照 → 估计"组合效果"，**不能拆出 WM**（只支持组合方案结论）
