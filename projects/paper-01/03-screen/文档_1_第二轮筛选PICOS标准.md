# 文档_1_第二轮筛选PICOS标准

**版本：** 1.0（2026-04-02）
**适用范围：** 第二轮人工摘要筛选（445条 → 预计100-150条）

---

## PICOS 纳入/排除标准

### P — 研究对象（Population）

| | 标准 |
|--|------|
| ✅ 纳入 | 健康老年人 ≥60岁，认知正常；有老年+青年对比组的也纳入（老年组须≥60岁） |
| ❌ 排除 | <60岁（无老年组）、MCI、痴呆、帕金森、卒中、精神疾病、癌症/HIV等躯体疾病患者、动物 |

### I — 干预（Intervention）

| | 标准 |
|--|------|
| ✅ 纳入 | 以WM为主要目标的认知训练（n-back、complex span、Cogmed、WOME等），计算机或纸笔均可，自适应或固定难度均可，最少2次session |
| ❌ 排除 | 记忆策略训练（记忆术）、多域训练（WM非主要成分且未单独报告WM效果）、纯体力训练、药物、单独脑刺激（tDCS/TMS联合WM训练可纳入）、商业视频游戏 |

### C — 对照（Comparison）

| | 标准 |
|--|------|
| ✅ 纳入 | 主动对照（其他认知训练）、被动对照（等待组/无训练组）、单组前后测 |
| ✅ 纳入 | 无对照组但报告调节因素分析的事后分析 |

### O — 结局（Outcome）

| | 标准 |
|--|------|
| ✅ 纳入 | 报告以下任一项：直接训练效应、近迁移（未训练WM任务）、远迁移（流体智力/执行功能/处理速度/注意力/情景记忆等） |
| ❌ 排除 | 仅主观认知感受、仅生活质量/情绪、仅神经影像（无行为结局） |

### S — 研究设计（Study design）

| | 标准 |
|--|------|
| ✅ 纳入 | RCT、准实验、单组前后测、事后分析（报告调节因素的） |
| ❌ 排除 | 综述/Meta/系统综述、案例报告、研究方案（protocol）、评论/社论/信件、横断面研究 |

---

## 快速判断流程（四步）

```
① 健康老年人（≥60岁）？       → 否 → E1排除
② WM为主的认知训练？           → 否 → E2排除
③ 报告认知结局？                → 否 → E3排除
④ 实证研究（非综述/protocol）？ → 否 → E4排除
⑤ 全是 → 保留
```

---

## 边界情况处理

| 情况 | 处理 |
|------|------|
| 年龄60-65岁，描述为"older adults" | 纳入 |
| 样本均值≥60但范围含<60岁 | 纳入，备注年龄范围 |
| MCI患者 | 排除 |
| WM训练+tDCS联合 | 纳入，备注"联合tDCS" |
| WM训练+体力训练联合 | 纳入，备注"联合体力训练" |
| 多域训练但单独报告WM训练效果 | 纳入，备注"多域训练" |
| 摘要无法判断年龄或干预 | 标"不确定"，进第三轮全文筛选 |
| 同一研究多篇报告 | 纳入主要结果文章，其余标注为重复报告 |
