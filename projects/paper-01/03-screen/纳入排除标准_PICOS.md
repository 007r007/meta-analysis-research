# 第二轮筛选：纳入/排除标准（PICOS格式）

适用阶段：人工摘要精读筛选（445条 → 预计100-150条）
制定时间：2026-04-02

---

## PICOS纳入标准

### P — 研究对象（Population）
✅ 纳入：
- 健康老年人，年龄 ≥55岁
- 认知功能正常（无MCI、痴呆、神经系统疾病）
- 若研究同时包含老年+青年对比组，纳入（只要有老年数据）

❌ 排除：
- 儿童、青少年、年轻成人（无老年组）
- 轻度认知障碍（MCI）患者
- 阿尔茨海默病/痴呆患者
- 帕金森病、多发性硬化、卒中等神经系统疾病患者
- 精神疾病患者（精神分裂症、抑郁症等）
- 癌症、HIV、糖尿病等躯体疾病患者（除非认知功能正常且为主要研究对象）
- 动物研究

---

### I — 干预措施（Intervention）
✅ 纳入：
- 以工作记忆为主要训练目标的认知训练
- 具体包括：n-back训练、复杂广度任务训练（complex span）、Cogmed、WOME、双重任务WM训练
- 计算机化或纸笔形式均可
- 自适应或固定难度均可
- 个人或团体形式均可
- 最少2次训练session

❌ 排除：
- 以记忆策略为主的训练（如记忆术、联想法）
- 多域认知训练（WM不是主要成分，占比<80%）
- 纯体力训练
- 药物干预
- 脑刺激（tDCS/TMS）单独使用（若与WM训练联合则纳入）
- 视频游戏/商业游戏（非专门WM训练设计）

---

### C — 对照组（Comparator）
✅ 纳入：
- 有对照组（被动等待、主动对照、假训练）
- 无对照组的单组前后测设计也纳入（但标注设计局限）

---

### O — 结局指标（Outcome）
✅ 纳入（至少报告以下之一）：
- 直接训练效应：训练任务本身的成绩变化
- 近迁移：未训练的WM任务成绩变化
- 远迁移：其他认知域成绩变化（流体智力、执行功能、处理速度、注意力、情景记忆等）

❌ 排除：
- 仅报告主观认知感受（无客观测量）
- 仅报告生活质量、情绪、日常功能（无认知结局）
- 仅报告神经影像结果（无行为认知结局）

---

### S — 研究设计（Study design）
✅ 纳入：
- 随机对照试验（RCT）
- 准实验设计（有对照组）
- 单组前后测设计（标注）
- 二次分析/事后分析（若报告调节因素）

❌ 排除：
- 综述、Meta分析、系统综述
- 案例报告、案例系列
- 研究方案（protocol，无结果）
- 评论、社论、信件
- 横断面研究（无训练干预）

---

## 调节因素相关（核心纳入条件）

本综述的核心目标是调节因素，因此优先纳入：
- 报告了个体特征与训练效果关系的研究（年龄、教育、基线认知、性别等）
- 比较了不同训练参数效果的研究（时长、强度、自适应性、任务类型等）
- 分析了迁移范围影响因素的研究

即使研究未专门分析调节因素，只要报告了足够的人口学信息和分组数据，也纳入（可用于叙述性整合）。

---

## 快速判断流程（人工筛选时用）

```
1. 研究对象是健康老年人（≥55岁）？
   → 否 → 排除（E1）

2. 干预是以WM为主的认知训练？
   → 否 → 排除（E2）

3. 报告了认知结局（训练效应或迁移）？
   → 否 → 排除（E3）

4. 是实证研究（非综述/方案/评论）？
   → 否 → 排除（E4）

5. 以上全是 → 保留，进入全文筛选
```

---

## 边界情况处理原则

| 情况 | 处理 |
|------|------|
| 年龄55-60岁，描述为"older adults" | 纳入 |
| MCI患者但认知功能轻度受损 | 排除（标注） |
| WM训练+体力训练联合 | 纳入（标注为联合干预） |
| WM训练+tDCS联合 | 纳入（标注） |
| 只有摘要，无法判断 | 标记"不确定"，进入全文筛选 |
| 同一研究多篇报告 | 纳入主要结果文章，其余标注为重复 |
| 非英文摘要 | 排除（E5） |

## 给CC的Excel第二轮筛选表建议

每行包含：
- 编号、标题、年份、期刊、摘要
- 判断列：纳入 / 排除 / 不确定
- 排除原因：E1/E2/E3/E4/E5/其他
- 备注列（记录边界情况说明）

建议由用户本人完成第二轮判断，遇到不确定的标记出来，最后集中讨论。
