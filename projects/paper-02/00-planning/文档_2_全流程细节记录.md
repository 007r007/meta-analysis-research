## 一、选题确定

### 背景
- Paper-01研究老年人（≥60岁）工作记忆训练，paper-02有意覆盖生命另一端（0-8岁），形成研究系列互补

### 选题理由（来源：00-planning/paper02_planning.md）
1. **聚焦父母教育而非复合SES**：父母教育是SES中测量最稳定、最可操作的单一指标，便于跨研究比较
2. **0-8岁神经可塑性窗口**：该年龄段是大脑发育关键期（突触修剪、髓鞘化、皮层组织化），环境影响留下持久痕迹
3. **多模态整合的必要性**：rsEEG、ERP、MRI三类证据各有侧重，系统整合尚缺
4. **研究空白明确**：中国样本研究几乎缺失；机制路径证据分散

### 4个核心研究问题
1. 父母教育水平如何影响儿童静息态EEG（功率/连接）？
2. 父母教育水平如何影响任务态ERP成分（P300/N200/N400等）？
3. 父母教育水平如何影响脑结构/功能神经影像指标？
4. 哪些机制路径（认知刺激、语言输入、应激暴露）在其中起中介作用？

### 预研工具
- Perplexity Deep Research：三轮检索验证选题可行性（具体记录见01-topic/主题确认.docx）

## 四、文献筛选（三轮）

### 第一轮：Python自动关键词筛选（2026-04-08）

**脚本**：`03-screen/脚本_2_第一轮Python自动筛选.py`
**输入**：1827条
**逻辑**：三概念同时出现才保留；E3判断采用两层神经词（见下）

| 排除码 | 含义 | 判断依据 |
|--------|------|---------|
| E1 | 年龄不符 | 标题+摘要无0-8岁年龄词 |
| E2 | 暴露不符 | 标题+摘要无父母教育/SES词 |
| E3 | 无神经指标 | 无精确层神经测量词（见下文神经词分层说明） |
| E4 | 综述/元分析 | 标题含systematic review/meta-analysis等 |

#### 神经词两层设计（E3核心逻辑）

**精确层**（NEURAL_SPECIFIC，必须命中至少一个才能通过E3）：
EEG/ERP/fMRI/fNIRS/DTI/MEG/spectral power/alpha power/theta power/resting-state/
diffusion tensor/functional connectivity/neuroimaging/brain imaging/cortical thickness/
cortical surface area/gray matter/white matter/brain structure/brain morphology/VBM/
visual evoked potential/MMN/N400/P300/Nc 等

**宽泛层**（NEURAL_BROAD，单独出现不足以通过E3）：
brain development / brain function / brain activity

**设计理由**：检索式阶段保留 brain development 等宽泛词是为了提高召回率（用于检索），
但在筛选阶段，仅凭这三个词无法确认文献使用了神经测量方法，因此单独出现时排除。
核心文献（Neville 2013、Kishiyama 2009、Troller-Renfree 2022）均含精确层词，不受影响。

**最终结果（v2脚本，更严格版）**：
| 结果 | 条数 |
|------|------|
| 保留 | **513** |
| E1（年龄不符） | 454 |
| E2（暴露不符） | 294 |
| E3（无神经指标） | 468（含198条仅靠宽泛词通过的噪音）|
| E4（综述） | 98 |
| **总计** | **1827** |

**说明**：初版脚本保留711条，分析发现198条仅靠brain development/function/activity命中神经组，
无任何具体测量词，属于方法层面噪音（如"poverty affects brain development"类文章）。
更新为两层神经词后降至513条，属合理第二轮工作量。

**输出**：`03-screen/数据_2_第一轮自动筛选结果.xlsx`（含颜色标注）
