## PICOS 纳入/排除标准

### P — 研究对象（Population）

| | 标准 |
|--|------|
| ✅ 纳入 | 儿童，年龄范围覆盖0–8岁（含婴儿期）；若研究含多年龄组，只要有0–8岁子样本且单独报告结果即纳入 |
| ❌ 排除（E1） | 样本年龄全部>8岁；临床样本（早产、神经发育障碍、脑损伤、癫痫等），除非单独报告健康对照组结果；动物研究 |

### I/E — 暴露（Exposure）

| | 标准 |
|--|------|
| ✅ 纳入 | 父母教育水平作为主要暴露变量，或在回归模型中有独立Beta/b系数及统计检验 |
| ✅ 纳入 | 复合SES（如教育+收入+职业），但教育的独立效应可单独提取（有各自beta系数） |
| ❌ 排除（E2） | SES仅为协变量，文献未报告教育的独立效应量（无beta/b值） |
| ❌ 排除（E2） | PCA合成SES主成分，教育权重隐含无法分离 |
| ❌ 排除（E2） | 暴露为其他环境因素（缺铁/机构养育/虐待/创伤/干预项目等），即使提到教育也不纳入 |

### O — 结局（Outcome）

| | 标准 |
|--|------|
| ✅ 纳入 | 任一神经测量指标：rsEEG（功率/连接）、ERP成分（MMN/P300/N400/Nc等）、fNIRS、fMRI（任务态/静息态功能连接）、DTI（FA/MD等）、structural MRI（皮层厚度/脑区体积/表面积/VBM）、MEG/MRS（若有） |
| ❌ 排除（E3） | 仅报告行为/认知结局（无神经测量）；仅主观问卷；仅眼动/生理指标（心率/皮电）非神经成像 |

### S — 研究设计（Study design）

| | 标准 |
|--|------|
| ✅ 纳入 | 横断面观察性研究、纵向观察性研究（队列/随访）、RCT（若含SES×神经的子分析） |
| ❌ 排除（E4） | 综述/系统综述/元分析/叙述性综述；研究方案（protocol）；评论/社论/信件；学位论文（已在第一轮排除） |
| ❌ 排除（E5） | 非英文全文（第一二轮未能识别的） |
| ❌ 排除（E6） | 无法获取全文PDF（经合理努力仍无法获取） |
| ❌ 排除（E7） | 与已纳入研究使用完全相同样本，且为重复报告（保留最完整/主要结果的那篇） |
| ❌ 排除（E8） | 其他原因（备注列说明） |

## 快速判断流程（五步）

```
① 样本有0–8岁儿童且非纯临床？    → 否 → E1排除
② 父母教育作为主暴露或有独立效应？ → 否 → E2排除
③ 报告神经测量指标（EEG/ERP/MRI等）？→ 否 → E3排除
④ 实证研究（非综述/protocol）？    → 否 → E4排除
⑤ 英文全文可获取？                → 否 → E5/E6排除
⑥ 全是 → 纳入
```

## 边界情况处理

| 情况 | 处理 |
|------|------|
| 年龄范围0–10岁，但多数样本≤8岁 | 纳入，备注实际年龄范围 |
| 年龄范围跨越8岁（如3–12岁），无0–8子分析 | 排除E1，备注"年龄跨越但无子分析" |
| 早产儿研究，含足月对照组 | 仅提取足月对照组数据，或若全文不可分离则排除 |
| 复合SES回归，教育有beta但p值未报告 | 纳入，备注"beta有但p未报" |
| 同一样本多篇文章报告不同神经模态 | 各篇均纳入，数据提取时标注"同一样本" |
| 干预研究（RCT）但包含SES分层分析 | 纳入，提取SES相关神经结局 |
| 摘要符合但全文数据无法提取教育效应 | 排除E2，备注"全文无教育独立效应" |
| 无法获取全文，摘要高度疑似符合 | 排除E6，备注"全文不可及" |
